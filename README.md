# SISA-Processor-on-FPGA
Design and physical implementation of a 16-bit multi-cycle processor based on the SISA architecture in VHDL.

• Developed the core architecture with SRAM Controller.

• Integrated I/O controllers, including a PS/2 keyboard, VGA display, LEDs and 7-segment displays.

• Implemented interruption and exception handling systems.

• Designed a basic virtual memory system and TLB.

All documentation available in Catalan.
